# VehicleLogBook

시설별 차량 운행기록 모바일 웹앱입니다.

## 구성
- 사용자 화면: 차량 선택, 운행자/동승자/운행목적 선택, 행선지 입력, 출발/도착 키로수 기록
- 상태 제어: 차량이 운행 중이면 새 운행 시작을 막고 "○○ 님이 운전 중입니다" 표시
- 관리자 화면: 차량/사용자/운행목적 편집
- 데이터 저장: 시설별 Google Sheets + Apps Script
- 엑셀 템플릿: 동일 헤더 구조의 예시 파일 제공

## 배포 구조
공통 프런트엔드 1개를 배포하고, 각 시설은 자기 시트의 Apps Script 웹앱 URL만 관리자 화면에 연결합니다.
따라서 10개 시설은 같은 앱 구조를 쓰되 데이터는 시설별 시트에 분리됩니다.

## 시트
- 설정: 시설명, 관리자PIN
- 차량: 차량번호, 사용여부, 정렬순서
- 사용자: 이름, 사용여부, 정렬순서
- 선택항목: 구분, 항목명, 사용여부, 정렬순서
- 운행기록: 기록ID, 운행월, 운행일자, 차량번호, 운행자, 동승자, 운행목적, 행선지, 출발키로수, 출발시각, 종료키로수, 종료시각, 운행거리, 상태, 작성일시
- 운행월/운행일자는 운행 시작 버튼을 누른 시각을 기준으로 자동 입력됩니다.
- 한 시트에 누적 저장하되 `운행월 + 차량번호` 기준으로 필터하면 차량별 월간 운행기록으로 바로 사용할 수 있습니다.

## 중요
열 순서는 자유롭게 바꿔도 됩니다. Apps Script는 열 번호가 아니라 1행의 헤더명으로 데이터를 찾습니다.
헤더명 자체를 바꾸면 연결이 끊기므로 헤더명은 유지해야 합니다.

## 연결 방법
1. 예시 Excel 파일을 시설별로 복사합니다.
2. Google Drive에 업로드 후 Google Sheets로 변환합니다.
3. 확장 프로그램 > Apps Script에서 apps-script/Code.gs 내용을 붙여넣습니다.
4. 웹 앱으로 배포하고 실행 권한을 승인합니다.
5. 생성된 웹앱 URL을 앱 관리자 화면의 API 주소에 입력합니다.
6. 관리자 PIN으로 시설별 차량/사용자/운행목적을 설정합니다.
7. 해당 시설 앱 URL을 QR로 만들어 사용자에게 배포합니다.
